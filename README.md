# Featured Projects

## BananaSense AI — Intelligent Fruit Ripeness Detection Platform

A production-grade AI-powered computer vision system for real-time banana ripeness detection using deep learning and transfer learning.

The platform classifies bananas into:

* Unripe
* Ripe
* Overripe

and generates intelligent agricultural insights including:

* confidence scoring
* shelf life estimation
* storage recommendations
* quality analysis
* spoilage risk assessment
* CSV analytics exports

### What I Built

* Trained and optimized a MobileNetV2 transfer learning pipeline
* Achieved ~97% validation accuracy
* Built FastAPI inference APIs
* Developed enterprise analytics dashboard in Next.js
* Integrated AI insights and visualization system
* Deployed full-stack architecture using Vercel + Render

`TensorFlow` `MobileNetV2` `FastAPI` `Next.js` `TypeScript` `Tailwind CSS` `Computer Vision`

🔗 Repository: https://github.com/Ankitnotnani/banana-sense-ai
🌐 Live Demo: https://banana-sense-ai.vercel.app/#dashboard
